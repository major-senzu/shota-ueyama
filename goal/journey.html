Journey / これまでの人生
中学・高校
野球部・副主将時代
チームの中で「真面目さ」を武器にポジションを確立。怒られない、信頼される構造を作り上げた。 一方で、自分が本質的にストレスを感じる「深く考える」「腹を割る」役割からは少し距離を取っていた。 後から振り返るとここが、現在の自己認識の出発点。
大学受験
リソース活用型の受験戦略
自分で深く考えるより、使える参考書・先生・先輩を最大限活用する戦略。 結果として慶應に合格できた一方、「自分の頭で深く考え抜く経験」は乏しかった。 仕組みを作って、あとは作業に落とし込む——典型的なスモールビジネス思考が形成された時期。
大学・KNOCK
国際関係会・日韓プロジェクト
組織に貢献できる人間として、複数のプロジェクトを推進。 「人を活かす設計」「自分の負担を最適化する設計」の両方をやってきた。得意領域の延長線。
2024–現在
Wanderlust / AIコンサルティング
AI領域に踏み込み、技術的にも事業的にも未知の領域に。 ここまでの「仕組みを作って楽になる」型から、「他者の本質的課題に向き合う」型への転換を求められている局面。 コンサル力・前進力・組織力の3つを、ここで具体的に磨いていく。
Core Issues / なりたい人間像までの課題整理
Complex / コンプレックス
「真面目」を武器に、本質的に大変なことから逃げてきた構造
中高の野球部副主将時代から繰り返してきたパターン。 真面目であることを盾に怒られない構造を作り、自分がストレスを感じる「深く考える」「腹を割る」プロセスから距離を置いてきた。 受験でも、自分で深く考えるよりリソースを活用する戦略を取り、結果として「深く考えなくても物事が進む構造を作る」のが極めて上手くなった。
Fear / 核となる恐怖
「30-40代で本質的に考える力が欠如している人間」になる恐怖
スモールビジネスで稼ぎ続けることは得意で最も儲かる。だがそれを続けることで 深さを失った人間 になる恐怖が、何より重い。 友達が少なく、愛せるパートナーもおらず、表面的・浅薄な人間になっている未来。 これがゴール設計の最大の駆動力になっている。
Talent / 才能の構造
仕組み化・人を活かす設計能力
自覚あり。ただしこの才能を「自分が楽になる仕組み」に使うと浅くなる。 「人間と世界の本質を設計に落とす」方向に転用できれば、深さと才能が両立する。 BuffettやKazuo Inamori型の経営者が、まさにこの転用に成功した例。
Open Question / 本当の問い
「自分が逃げずに向き合いたい対象は何か?」
コンサル力・前進力・組織力を、どのドメインで発揮するのか。 このドメイン(=向き合いたい対象)が決まれば、外的選択肢(商社 / Wanderlust / 他)は自動的に決まる。 逆に、ここが決まっていないまま選択肢を比較しても答えは出ない。 だからこの2年は、行動しながら向き合いたい対象の解像度を上げることに賭ける。
